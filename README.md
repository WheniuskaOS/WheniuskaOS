### Merhaba, ben Yiğit 👋

C#, .NET masaüstü uygulamaları, Web API ve Discord botları geliştiren bir yazılım geliştiricisiyim.

#### 🛠️ Kullandığım Teknolojiler ve Araçlar
* **Diller:** C#, SQL, HTML/CSS
* **Framework & Altyapılar:** .NET, Windows Forms, WPF, ASP.NET Core Web API, WebView2
* **Kütüphaneler & Araçlar:** Discord.Net, Lavalink, Git, Visual Studio, VS Code

#### 🚀 Öne Çıkan Projelerim
* **UltraBrowser & UltraBrowserWPF:** WebView2 altyapısı kullanılarak C# ile geliştirilmiş masaüstü web tarayıcıları.
* **SystemMonitor:** Donanım ve sistem kaynaklarını anlık izleyen Windows Forms uygulaması.
* **BatteryMonitor:** Pil seviyesi %20 ve %80 sınırlarına ulaştığında uyarı veren sistem tepsisi (system tray) uygulaması.
* **Synapse:** Web API ve WPF masaüstü istemcisini birleştiren çok katmanlı çözüm.
* **MRX Bot Serisi:** Lavalink müzik altyapısı, moderasyon ve kelime oyunu modülleri içeren C# Discord botları.
